* 최대공약수
public static int gcd(int a, int b) {
	while(b != 0) {
		int temp = a % b;
		a = b;
		b = temp;			
	}
	return a;
}

* 최소공배수

* 코테 Rule
1. 숫자가 2번 이상 나오면 무조건 상수로 빼기
2. 숫자가 1번만 나오고, 문제에서 기준이 너무 명확하면 그냥 써도 OK
3. ‘의미’를 이름으로 보여주고 싶으면 1번이어도 상수로 빼기
4. 입력값(매개변수)은 상수로 만들지 말기
예: YEAR, PRICE, LIMIT 같은 이름이 의미를 살릴 때
5. 부동소수점(0.8 같은 거) 나오면 가능하면 정수 연산으로 바꾸기
예: price * 80 / 100 처럼

* 약수의 특징
1. 약수는 항상 쌍으로 나옴
2. 약수 탐색은 √n까지만 보면 됨
3. n이 제곱수면 “가운데 약수”가 하나만 있음
4. 약수의 개수는 소인수분해로 구할 수 있음
예: 소인수분해 n = p^a * q^b * r^c ... 이면 약수 개수 = (a+1)(b+1)(c+1)...
